### 1.2 Data flow

`ui.startGame(opts)` → `CG.start(opts)` → `CG.createGame(opts)` builds `G` → `render.attach(G)` (prebakes terrain, fog canvas, minimap base, clears sprite caches) → `ui.onStart(G)` (builds DOM sidebar) → `input.attach()` → `requestAnimationFrame(frame)`.

Per frame (`game.js:182-209`): `frame(now)` → N × `CG.update(G, DT)` → `input.frame(G, dtReal)` (edge scroll, cursor, hover) → `render.draw(G, alpha, dtReal)` → `ui.frame(G, dtReal)` (10 Hz DOM refresh) → perf EMA (`G.perf.sim/draw/fps`, α=0.05).

Sim → presentation goes through: (a) `CG.notify(G,pid,text,opts)` → `CG.ui.toast` + `CG.audio.play/speak`, cooldown per key (default 4 s) stored in `G.msgTimes`; sets `G.lastAlert`; (b) `CG.fx.*` pushes particles/decals into `G.particles/G.decals` (sim-owned arrays); (c) `CG.audio.play(name,x,y)` positional. Presentation → sim: input mutates `G.sel`, `G.mode`, `G.cam`, calls `CG.order*`, `CG.enqueue`, `CG.usePower`.

### 1.3 Game loop

- Fixed step `DT = 1/60`. Accumulator `acc += dtReal * G.speed`; `dtReal` clamped to 0.25 s; at most **10 steps/frame**, then `acc = 0` (spiral-of-death guard). Speed presets 1 / 1.5 / 2.
- Interpolation: at the start of `CG.update` each entity copies `px=x, py=y, pangle=angle, pturret=turret`; render uses `alpha = acc/DT` (`1` when paused) with `lerp` / `lerpAngle`.
- Tick cadences inside `CG.update`: `rebuildSpatial` every tick; `refreshPlayer` every 15 ticks staggered by player id (`tick % 15 === p.id`); production, powers, AI every tick (AI self-throttles by `diff.think` 1.4/0.8/0.5 s); `path.process(28)` = up to 28 A* searches/tick; units then buildings; projectiles, strikes, particles; reveals decay; `map.regrow` every 300 ticks; `updateFog` every 6 ticks (10 Hz); shake decay; `removeDead` (only if `G.dirty`); `checkEnd` every 30 ticks.
- Victory: a player is defeated when it has no counted building and no MCV unit; defeated players' units are killed and derricks go neutral. End screen shown 2.5 s after `G.overAt`.

### 1.4 Entity model

Plain objects in `G.entities` (array) + `G.byId` (Map); ids from `G.nextId++`. `kind: 'unit' | 'bld'`, `def` = direct reference into `CG.UNITS/BUILDINGS`, `owner` = player index or `-1` neutral. Removal is deferred: `CG.kill` sets `alive=false`, `hp=0`, `G.dirty=true`, frees map cells (`block/bld/reserve`), updates stats, strips from selection; `removeDead` compacts the array once per tick. Unit record has ~55 fields (movement: `goal, path, pathIdx, pathPending, pathReq, stuckT, stuckD, repaths, repathT, moving, speedNow`; combat: `target, scanT, cd, burst*, firedT, hitT, lastAttacker, disabled`; harvesting: `carry, hs, resTile, harvT, fieldX/Y, waitT, refId`; misc: `guardX/Y, anim, sel, kills (never written), group, _qs`). Building record: tile rect `tx,ty,w,h,x0,y0,x1,y1` and centre `x,y`, `built` 0→1 over 1.2 s, `selling`, `repairing`, `rally`, `seen` (bitmask of players who have seen it), `dockX/Y`, `incomeT`. Bitmasks `seen`/`revealed` index by player id (`1 << pid`).

Player record (`game.js:33-43`): `credits, powerProd, powerUse, lowPower, hasRadar, queues{bld,inf,veh,air}` each `{items[], progress, paid, ready, stalled}`, `prodRR`, `powers{id:{charge,avail}}`, `owned{type:count}`, `unitCount`, `stats{…}`, `vis/explored` `Uint8Array(map.n)`, `incomeMult/buildMult`, `ai`.

### 1.5 Data model (data.js)

- `WARHEADS[wh][armor]` damage matrix (11 warheads × 4 armour classes `inf/veh/air/bld`), e.g. `AA: {inf:0, veh:0, air:1.3, bld:0}`; a 0 entry makes the target un-targetable (`canTarget`).
- Weapons: `dmg, cd, range (tiles→px), minRange, splash, scatter, burst, burstGap, speed, shake, targets:'g'|'a'|'ga' → hitsGround/hitsAir`, `proj: bullet|lob|missile|shell|rocket|arty|zap|self`.
- Units: `cat inf|veh|air`, `cost, time, hp, speed (px/s), sight (tiles), radius, turn (rad/s defaults 12/3.2/5), prereq[]`, flags `mcv, harvester, engineer, detector, stealth, kamikaze, squad/spawn, hidden`.
- Buildings: `w,h` tiles, `power` (+produce/−consume), `tab`, `produces`, flags `conyard, refinery, radar, tech, defense, needsPower, capturable, noCount, income/incomeEvery`.
- Factions: unit roster, 2 powers, `mods {defRange, prodInf, prodVeh, bldCost}`. Difficulty: `think, income, build, harvPerRef, firstWave, waveBase, waveGrow, counters, powers, engineers`.

### 1.6 Map (map.js)

Size 64/88/112 tiles, `TILE = 32` px. Generation: three seeded value-noise fields (elevation e: water < 0.3, rock > 0.71; moisture m > 0.66 forest), averaged over the 4 rotational copies (`symAvg`) so the map is exactly symmetric; rock frame on the border; start positions at `s = max(8, round(W*0.12))` from each corner (`startsFor(count)` picks opposite corners for 2); carved corridors (`carve` with sine wobble) and discs (`setDisk`); 4 resource field specs mirrored 4× with hash-jittered edges; 4 neutral derricks; flood fill from start 0 turns unreachable ground into rock; BFS water depth for shading; `block[i] = terrain !== GROUND`. Helpers worth keeping: `idx, inBounds, passable, sym, nearestFree(tx,ty,maxR,pred)` (ring search), `takeRes`, `regrow`.

### 1.7 Spatial hash (spatial.js)

`cells = Array(cols*rows)` of arrays, cell = 128 px; `clear()` + reinsert all alive entities each tick (`rebuildSpatial`), buildings inserted into every covered cell (`insertRect`). `query(x,y,r,out)` fills a caller array and dedups with a monotonically increasing `stamp` written onto `e._qs` (non-reentrant by design). `edgeDist(e,x,y)` = distance to building rect edge or to unit circle edge.

### 1.8 Pathfinding (path.js)

A* over `map.block` (8 directions, diagonal cost √2, no corner cutting through blocked orthogonal neighbours), octile heuristic, binary heap storing tile indices with `hpos` for decrease-key (`_up`), `seen/closed` as `Uint32Array` generation stamps (reset when gen overflows), `maxIter = min(n, 14000)`; if the goal is unreachable returns the path to the best-h node. Asynchronous API: `request(u,x,y)` enqueues (one pending request per unit, latest wins) and `process(budget)` computes up to 28/tick, writing `u.path` as waypoints (`computeWaypoints`): tile centres, exact final point if reachable, then greedy string-pulling using `CG.lineClear(m, x0,y0,x1,y1, rad)` (samples every 8 px plus two parallel rays offset by `rad`; look-ahead window 14 waypoints). If target tile is blocked it retargets `nearestFree(…, 8)`.

### 1.9 Fog (fog.js)

Per player `vis` (cleared every update) and `explored` (persistent) `Uint8Array(map.n)`. Precomputed circle offset tables for radii 0..16 (`dx²+dy² <= r²+0.8r`). Every alive owned entity stamps its `def.sight` (unfinished buildings: 3). Temporary `G.reveals` (satellite scan etc.) also stamp. Stealth: for each stealth unit, enemies within 11 tiles reveal it if within `detector ? sight : radar ? 8 tiles : 2.6 tiles` → `e.revealed` bitmask. Buildings seen once get `seen |= 1<<pid` (ghosts drawn in fog). `G.fogDirty` tells render to re-upload the fog ImageData. `CG.visibleTo(G,e,pid)` (units.js:138) is the single visibility predicate used by AI, render, input.

### 1.10 Combat (combat.js)

`fire` sets `cd = w.cd*(0.95..1.05)` (seeded RNG), sets up bursts, then `launch`: muzzle offset along `s.turret`, optional scatter (uniform disc via `sqrt(rng)`), then by `proj`: `bullet` = instant hit + tracer fx; `zap` = hack (`disabled = max(disabled, hackTime)`); `self` = kamikaze explode+die; otherwise push a projectile `{x,y,z,sx,sy,tx,ty,tz,t,dur=d/speed,arc,…}`. `updateProjectiles`: missiles home (turn 7 rad/s, speed from weapon, 4 s lifetime); ballistic ones lerp with parabolic `h = arc*4k(1-k)`; smoke trail puffs at fixed intervals. `impact` → `explodeAt` (splash: all enemies with `edgeDist <= r`, falloff `max(0.25, 1 - 0.6 d/r)`, direct target full) or single hit if within 20 px. `damage(G,t,amount,wh,src)`: `hp -= amount * WARHEADS[wh][armor]`; retaliation (idle unit targets attacker), human alerts with per-key cooldowns and minimap `ping`, AI `onAttacked`, kill. Powers: `reveal`, `strike` (delayed area, `SUPER` warhead, falloff `max(0.3, 1-0.7d/r)`), `barrage` (16 shells over 4 s spawned as `arty` projectiles), `cyber`, `emp`. Particles: cap **1 800** (FIFO), decals cap **220**; particle kinds flash/flash2/tracer/zap/smoke/dust/spark/fire/debris(z,vz gravity 400)/ring/shock/glitch/text/corpse/delayBlast. `shake(G,amount,x,y)` distance-attenuated, cap 16 px, decays `7/s`.

### 1.11 Unit behaviour (units.js)

Order FSM in `updateUnit`: `harvest` (states `find→goto→mine→toRef→goingRef→unload`, claims per tile in `G.claims`, mine 25 units / 0.3 s, unload 320/s), `capture|repair` (engineer consumed on contact), `deploy` (MCV → conyard via `canPlace(..., {anywhere:true})`), `attack` (chase with repath every 0.8 s if target moved > 40 px), `amove` (acquire within `max(range, sight*0.85)`), `move`, else `combatIdle` (scan every 0.3–0.4 s, leash **7 tiles** from guard point, return to guard point). `acquire` scores targets `d / warheadMult` plus penalties (+420 unarmed building, +120 armed building, +160 unarmed unit, +40 harvester, −40 current target). Movement `step`: vehicles rotate first (`turnTo`), speed scaled by `cos(angDiff)` (0 beyond 1.4 rad); infantry/air move directly; arrive radius 4/6 (last) or 10/14 (intermediate); stuck detection every 1.2 s (`d > stuckD-6` → repath, max 4 repaths). `tryMove` tests 5 sample points (centre + 4 at 0.6·radius) and allows sliding on one axis; a unit already inside a blocked tile is let out. `separate`: pairwise push from spatial query (radius+18), mass table inf 1 / veh 4 / air 1 (harvester ×1.5), clamp 2 px/tick. `formationSlots/groupMove`: square grid of slots spaced `max(2r+6,16)`, greedy farthest-unit-first assignment.

### 1.12 Rendering pipeline (render.js + sprites.js)

1. **Retina/resize** (`R.resize`): `dpr = min(devicePixelRatio, 2.5)`; canvas backing store = CSS size × dpr; `R.cssW/H` kept in CSS px. World transform per frame `setTransform(k,0,0,k,-cx*k,-cy*k)` with `k = dpr*zoom`; screen-space overlays use `setTransform(dpr,…)`. Camera `G.cam {x,y,zoom∈[0.6,1.6],vw,vh}` in world px, `clampCam` centres when the map is smaller than the view.
2. **Terrain prebake** (`buildBase`): one offscreen canvas at **PPT = 8 px/tile** (e.g. 88×88 map → 704² px): per-tile colour from theme (water depth lerp, rock shade, ground shade, shore blend 0.7, forest darkening, resource tint), two separable box blurs (r=3 then r=2) on a Float32 temp, then per-pixel hash noise ±7; drawn per frame with a single `drawImage` sub-rect scaled 4× (smoothing on). Minimap base = the same bitmap at 2 px/tile plus rock/forest tints.
3. **Sprite atlas by scale** (`buildAtlas(map, s)`): decorative rocks (6×52²), trees (6×48²), details (8×32²), crystals (4 levels × 3) drawn into canvases scaled by `s = round(dpr*zoom*4)/4`; rebuilt on zoom change only after a **220 ms** debounce (`R.zoomChanged` sets `atlasPending`). Buildings: `sprites.buildingSprite(type, owner, fid, scale)` cached in a Map keyed `type|owner|fid|scale` with `MARGIN = 10` px for shadows; icons cached at 112×64 @2×. `sprites.clearCache()` on every `attach`.
4. **Per frame order**: clear → terrain → `drawTiles` (visible tile range ±1, variant chosen by `hash2(tx,ty,seed)`, animated water glints, refinery dock pads) → decals (fade in last 30 % of life) → cull + collect `visible` (ground) and `airList`; **painter's sort** by `y` (buildings use `y1-6`) → ground particles (corpse/dust) → entities (`drawBuilding`: build-up clip reveal, sell fade, disabled tint, repair icon, damage smoke; `drawUnit`: translate to interpolated pos minus `z`, stealth alpha, hover bob for air) → projectiles → air shadows (offset by `z*0.15`) → air units → air particles → strikes → fog → world overlays (placement ghost + per-cell validity, build-radius rects, rally lines, selection brackets, hp bars, order markers, power targeting ring) → screen overlays (box select, low-power vignette) → minimap every 5th frame.
5. **Fog drawing**: `fogImg` ImageData at **1 px per tile** (alpha 0 visible / 150 explored / 255 unexplored, rgb 4,6,9), uploaded only when `G.fogDirty`, drawn scaled to map size with image smoothing → cheap soft fog.
6. **Vector art**: all units/buildings are procedural Canvas paths parameterised by `(ctx, colour, factionStyle, t, moving, turretAngle)`; colour helpers `shade(hex,f)` (returns `'rgb()'`), `mix(a,b,t)` (returns hex), `rgba(hex,a)`, `rgb()` parser that now accepts both forms (this is the fixed bug site, sprites.js:9-23).

### 1.13 Input model (input.js)

Pointer Events only (`pointerdown/move/up/cancel`), branch on `pointerType === 'touch'`. Mouse: left drag > 6 px → box select (box anchored in world coords so edge-scroll during drag is correct), click → `leftAction` (mode-dependent) with double-click window 350 ms; right button **or ctrl+click on Mac** (`isRightClick`) → `rightAction` (cancel mode or contextual `I.command`); middle button → pan with pointer capture; wheel → pan (`deltaMode` scaling 1/24/400) or zoom with ctrl (`exp(-deltaY*0.01)`), Safari `gesturestart/change` suppressed; edge scroll 14 px band at `950/zoom` px/s only when `document.hasFocus()` and mouse inside. Touch state machine: `tap` → `pan` (>10 px) or `box` (hold ≥ 450 ms then move, no mode); long-press (≥450 ms, <8 px) selects same type on screen; two fingers → `pinch` (zoom about midpoint + pan). Minimap: left click/drag centres camera, right click issues `I.command`. Modes in `G.mode`: `place{item,tx,ty,ok,reason}`, `amove`, `power{id}`, `sell`, `repair`; Shift keeps mode. Keyboard (`onKey`, ignores inputs/selects): digits with Ctrl/Alt = set group, plain = select group (double tap centres), Esc cascade (mode → selection → pause), P/F10 pause, A/S/D/H/Space/Q/W/E/R/V/+/-/F2/Tab. Cursors are inline SVG data URIs with fallbacks (`CUR` table). `I.pick` prefers units (radius +5 inf / +3 others, air bias) over buildings and respects fog.

### 1.14 UI model (ui.js, index.html, style.css)

DOM sidebar (276 px, 228 px under 900 px width) with: minimap/radar-off overlay, credits (animated towards real value at rate 8/s) and power bar, powers row, 5 tabs, build grid (icons are `<canvas>` filled from `sprites.icon`), selection panel, 8 command buttons with `<kbd>` hints. Settings object `S` persisted at `localStorage['cg2026.settings']` (faction, opponents, difficulty, mapSize, credits, theme, sound, music, voice, speed); segmented controls generated from `SEGS` into `.seg[data-key]`; `syncMenu` toggles `.on`. Update loop at **10 Hz** (`uiT >= 0.1`) with per-item dirty signatures (`sig` string compare) to avoid DOM writes. Toasts: max 5, fade at 3.6 s, removed at 4.3 s, kinds info/warn/alert, `aria-live="polite"`. Tooltip positioned left of element, flips right, suppressed on `(hover: none)`. Pause on `visibilitychange`; Esc closes help (capture listener). End screen table of per-player stats. CSS: tokens in `:root`, clip-path chamfered panels, `env(safe-area-inset-*)`, `touch-action:none` on canvas, `user-select:none`, breakpoints at 900 px width and 640 px height.

### 1.15 Audio model (audio.js)

`AudioContext` created lazily on first gesture (`A.init` from pointerdown/menu buttons), graph: sources → `sfx`/`mus` gains → DynamicsCompressor (−16 dB, knee 12, ratio 6) → master 0.7. A 1 s white-noise buffer is shared. Two primitives: `noise(t,dur,filterType,f0,f1,Q,gain,pan,attack)` and `tone(t,oscType,f0,f1,dur,gain,pan,attack)` with exponential envelopes. **33 SFX recipes** in `SFX`. Throttles: `MIN_GAP` per name (25 ms default), max **24 concurrent voices** (decrement after 400 ms). Positional: listener = `G.cam`; full volume within 0.55×view, linear falloff to 0 at ~1.3× further; pan = `(x-cx)/(0.8 vw)` clamped ±0.8. Speech: `speechSynthesis` with pt-PT voice preference (`onvoiceschanged`), rate 1.08, pitch 0.75, one utterance per 1.5 s, skipped if speaking. Music: 96 BPM, 16-step sequencer, D-minor bass line + 4 chord pads, kick on steps 0/6/10, hats, scheduled 150 ms ahead by `setInterval(40)`.

### 1.16 AI model (ai.js)

Tiny behaviour-tree DSL (`BT.sel/seq/all/cond/act`, `BT.tick(node, ai)` calling functions with `this = ai`). Root is `all(...)`: base recovery (no conyard → deploy/buy MCV), `economy` (harvesters = `refs*harvPerRef` ≤ 8, auto-repair < 70 % hp if credits > 500, idle harvesters back to work), `structures` (fixed 30-item `PLAN` build order with power surplus check `< 25 → power`, skip list for 40 s after failed placement, extra defences when credits > 2 500; placement via `findSpot` ring search with 1-tile corridor rule `ringClear`, refineries next to `bestField`, defences toward `threatDir`), `production` (per queue ≤ 2 items; weights `ai .32 / av .45 / aa .08 / arty .12` shifted by decayed sightings `seen[cat]` ×0.97/think), military selector (`defend` if enemies within 15 tiles of base or 64·√2.2 px of a building or attacked in last 8 s; `pressWave` gather→attack with re-target every 6 s and reinforcement merge; `retreat` when wave strength < 30 % of start; `launchWave` when idle strength ≥ `waveNeed = min(9000, waveBase + waveNum*waveGrow)` or 40 idle units or 150 s elapsed at ≥ 50 %; `rallyIdle` 6 tiles toward threat), scouting (≤ 1/3 scouts, fastest cheap unit, after 35 s), engineers for derricks within 34 tiles (after 150 s), powers (`bestCluster` greedy density, min value 1 800 for strikes / 600 others). Memory: `known` Map of enemy buildings seen, `threat` position with timestamp. Strength = Σ cost × hp fraction.

## 2. Reuse plan for turn-based isometric tactics (Battlescape) + strategic globe (Geoscape)

## 3. Pitfalls and learnings → engineering rules for the next game

1. **Colour representation bug (sprites.js).** `shade()` returns `'rgb(r,g,b)'`, `mix()` returns `'#rrggbb'`, and both are fed back into `rgb()`; e.g. `barrel(ctx, …, shade(h,-0.2))` then calls `shade(c,-0.35)` on an `rgb()` string, which the original hex-only parser turned into `NaN` → invisible/black parts. Fixed by a dual-format parser (sprites.js:11-23). **Rule:** one canonical colour type in code (`[r,g,b]` ints or packed `0xRRGGBB`); helpers take and return only that type; convert to a CSS string once, at `ctx.fillStyle =`; add a 10-line unit test `shade(shade(c,a),b)` and `mix(shade(…),…)`.
2. **Service worker served stale `index.html`.** `sw.js` is pure cache-first (`caches.match(req) || fetch`), so after the first visit every HTML/JS file is frozen until the hand-edited `CACHE = 'jogos-familia-v2'` string changes; worse, the catch-all fallback `caches.match('./index.html')` answers **any** failed GET (e.g. a new JS file not yet cached) with the hub HTML → `SyntaxError: Unexpected token '<'`. **Rules:** (a) network-first or stale-while-revalidate for `.html` and `.js`, cache-first only for immutable assets; (b) derive the cache name from a build/commit stamp written into `sw.js` and as `?v=<stamp>` on `<script src>`; (c) only fall back to `index.html` when `e.request.mode === 'navigate'`; (d) listen for `controllerchange` and show a "new version, reload" toast; (e) `?nosw=1` dev switch that unregisters; (f) QA script asserts the served `index.html` contains the current stamp.
3. **GitHub default branch points at a stale branch.** `git remote show origin` → `HEAD branch: claude/trip-expense-splitter-bnv2T`; a plain `git clone` checks out the 2026-03 trip splitter, not the game on `main`. **Rules:** `gh repo edit --default-branch main`; delete merged `claude/*` branches; README quick-start is literally `git clone … && cd HelloWorld && git switch main && python3 -m http.server 8000`; GitHub Pages deploys from `main`; add a `make check-branch` that fails if `origin/HEAD` ≠ `main`.
4. **Safari `file://` restrictions.** The code already avoids ES modules and `fetch()` of data files (all data is JS) and registers the SW only under `http(s)` (index.html:177). **Rules:** keep "no modules, no fetch, no cross-file imports" for the shipped build **or** commit to always serving over HTTP (ship `serve.command` for macOS: `python3 -m http.server 8000` + `open http://localhost:8000`); AudioContext only after a gesture (done); `speechSynthesis` voices are async (`onvoiceschanged`, done); test both Safari and Chrome on macOS in the QA script.
5. **Untested advertised capability.** README claims Node AI-vs-AI; `opts.humanAI` crashes (game.js:29 vs ai.js:89). **Rule:** the headless harness lives in the repo (`tools/sim.js --seed 1 --minutes 30 --p0 hard --p1 normal`) and runs in CI; capability claims in README link to the script.
6. **QA script not committed.** Playwright QA was run during the session but nothing exists in the repo (no `package.json`, no `qa/`). **Rule:** `qa/playwright.spec.js` that starts `http.server`, opens the game, clicks Start, fast-forwards (`G.speed`), fails on any `console.error`/`pageerror`, screenshots at t=0/30/120 s, asserts `G.perf.fps > 50` and `G.perf.draw < 8 ms` at 1 280×800 @2× dpr; plus `tools/sim.js` determinism check (two runs same seed → equal hash). Run both before every push.
7. **Sim ↔ presentation coupling.** 20 `CG.notify` calls with hard-coded Portuguese text inside sim modules; `CG.fx` writes to `G.particles` from render (`drawDecals`, `drawBuilding`, `drawUnit` spawn smoke) so the renderer mutates game state; `sprites.js` reads the global `CG.G`. **Rules:** sim pushes typed events (`G.events.push({t:'lowPower', pid})`) consumed and cleared by UI/audio each frame; all player-visible strings in `i18n/pt-PT.js` keyed by id; particles/decals live in a render-owned `FX` object, never in `G`; nothing reads `CG.G` except `game.js`/`ui.js`.
8. **State is not serialisable.** `G` is cyclic (`player.ai.G`), contains `Map`, typed arrays, `Pathfinder`/`SpatialHash` instances, closures (`ai.strength`), and entities hold `def` object references. X-COM needs save/load (Geoscape + mid-battle). **Rules:** `G` = plain JSON-able data only (ids not refs: `e.type`, `e.targetId`; `Uint8Array` serialised as base64 or plain arrays); derived caches (`byId`, `unitAt`, fog bitmaps, prebaked terrain) rebuilt by `rebuildDerived(G)` after load; AI memory stored as plain objects on the player; RNG streams expose `getState/setState`; `schemaVersion` field + migration table; test `hash(load(save(G))) === hash(G)` and "resume then step N turns = step N turns without save" in CI; autosave at the start of every Battlescape turn and on every Geoscape day; manual export/import as a `.json` download (Safari may evict site storage — see uncertain) and IndexedDB rather than `localStorage` for multi-MB saves.
9. **Determinism caveats.** Sim is deterministic in one engine (verified), but uses `Math.sin/cos/atan2/hypot/pow` in gameplay paths (movement, scatter, speed by heading), which are not bit-identical across V8/JavaScriptCore. **Rules:** turn-based X-COM uses integer arithmetic for everything that affects outcome (TU, accuracy rolls, damage, LOS via integer Bresenham/DDA, iso maths in integers); floats only for animation; one `rng.combat` stream; a replay = `opts + command log`, which also gives free bug reports.
10. **Non-reentrant scratch state.** Module-level `_n`/`_q` arrays (units.js:6, combat.js:6, fog.js:6, entities.js:113) and the `e._qs` stamp make `spatial.query` unsafe to nest; currently safe only by accident of call order. **Rule:** query functions allocate or take a caller-provided array; avoid writing bookkeeping onto entities.
11. **Global singletons as modules.** `CG.render/input/ui/audio` keep private module state (`let G, cv, ctx…`), `attach()` re-initialises; there is exactly one game at a time. **Rule:** for X-COM (Geoscape and Battlescape coexisting, saves) make modules factories/classes receiving `G` explicitly; keep the IIFE+namespace loading if staying build-less, but never read `CG.G` inside a module.
12. **Magic numbers everywhere.** ~2 800 numeric literals in gameplay modules (LEASH `7*T`, arrive radii 4/6/10/14, scan 0.3 s, repath 0.8 s, cooldowns 4/8/15/20/25 s…). **Rule:** `tuning.js` (all gameplay constants, named, with a comment) separate from art constants; difficulty tables reference tuning names.
13. **Dead code and hidden flags.** `u.kills` never incremented; `G.groups` never used; `CG.revealAll` and `G.revealMap` (debug reveal, read in 10 places, never set) exist without a UI; `ai.onUnitBuilt` is a no-op hook; `R.drawMinimapNow` unused. **Rule:** ESLint `no-unused-vars` + a visible debug panel (`?debug=1`) listing all cheat flags.
14. **Manifest mismatch.** `manifest.json` still names "Reviravolta" with `start_url: reviravolta.html`; `command-2026/index.html` links no manifest; icons are referenced as `../icon-192.png`. **Rule:** one manifest per installable game (`command-2026/manifest.webmanifest`, `scope` = its folder), run Lighthouse PWA audit in QA.
15. **Single giant commit.** 8 781 lines in one commit (`f52103c`). **Rule:** one commit per module/milestone, tags `v0.x-playable`, CHANGELOG, and never force-push `main`.
16. **Good patterns to keep deliberately:** fixed-step accumulator with step cap; snapshot-then-interpolate; deferred removal; typed arrays + generation stamps; per-tick cadence table; dirty-signature DOM updates; caches keyed by quantised scale with debounce; guard every optional subsystem (`if (CG.audio)`) so headless runs work; `aria-live`, `focus-visible`, safe-area insets, `touch-action:none`, `(hover:none)` tooltip suppression.

## 4. Code-quality observations

**Good**
- Deterministic sim given `seed` (verified by hash equality), cheap enough to run **>100× real time** headless (0.08–0.10 ms/tick, ~10 000 ticks/s), which enables AI-vs-AI balance sweeps.
- Clean separation of "data as tables + derivation loop" (data.js) from behaviour; `prereq[]` arrays and `typeDef` make tech trees trivial.
- Allocation-conscious hot paths (typed arrays, reused scratch arrays, FIFO caps on particles/decals, `removeDead` compaction only when dirty, fog recomputed at 10 Hz, UI at 10 Hz, minimap every 5 frames).
- Robustness guards: A* `maxIter` + nearest-node fallback, spiral-of-death cap, stuck detection + repath limit, audio voice/gap throttles, try/catch around storage/speech/audio nodes.
- Input handles Mac specifics (ctrl+click = right click, trackpad pinch via wheel+ctrl, Safari gesture events) and iPad touch in one code path; retina handled once in `resize` with transform scaling, no per-draw dpr maths.
- Consistent module idiom, comments at top of each file, no dependencies, works from `file://`.

**To do better**
- Module boundaries: load order is implicit (a `<script>` list); entities.js calls units.js (`orderHarvest/orderMove`) and units.js calls entities.js, combat.js calls units.js (`canTarget`) and vice-versa (`fire/launch`) — a dependency cycle group `entities↔units↔combat`. Define layers: `core → data → map/grid → rules (pure) → ai → presentation`, with rules never importing presentation.
- Testability: functions take `G` and mutate; introduce pure helpers for rolls (`hitChance(shooter, weapon, mode, dist)`), TU costs (`moveCost(tileA, tileB)`), LOS (`canSee(map, from, to, light)`) and test them in Node with fixed seeds; the committed harness from §3.5/3.6.
- Naming: single-letter module aliases (`R`, `S`, `U`, `I`, `A`), overloaded `p` (player/particle/projectile/point), `hs` (harvest state), `st` (style or state), `k`, `_n`; `G.path` is a `Pathfinder` while `u.path` is an array; `e.sel` boolean vs `G.sel` id list. Use full nouns and a glossary.
- State serialisation (detailed in §3.8): the RTS has no save because `G` cannot be stringified; X-COM state to persist = Geoscape clock, funding/score per country, bases (facilities grid, stores, soldiers with stats/wounds, craft with fuel/weapons), research/manufacture progress, UFO/mission schedule, UFOpaedia unlocks, options; Battlescape = mutable tile arrays (destroyed walls, fire/smoke timers), units (position, facing, TU/energy/health/morale/stun, inventory with ammo counts), floor items, turn number/phase, side visibility, RNG stream states, pending animations (should be empty at save points: save only between actions).
- i18n: UI copy is inline in HTML and JS (pt-PT); the lead will translate player-facing text, so strings must be data.
- Tooling: add `package.json` scripts (`serve`, `sim`, `qa`, `lint`), ESLint + Prettier config, `.editorconfig`, and GitHub Actions running `node tools/sim.js` + Playwright on push.
- Rendering budget for iso: current draw loop culls by rectangle and sorts every frame; for 60×60×4 use per-level chunk prebake + dirty chunks, and sort only dynamic sprites (units/items) by `x+y+z`.
